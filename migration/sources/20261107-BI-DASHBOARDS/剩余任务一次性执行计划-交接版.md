## 12. 已知坑

1. `PUT /api/v1/chart/{id}` 只改 params 不会更新 `slices.viz_type` 列，而前端按列值选插件。
2. `dist_bar` 未注册。`pie` 已注册，但必须用单数 `metric` 加 `groupby`。`echarts_timeseries_bar`、`big_number_total`、`table`、`pivot_table_v2` 有现役样本；`echarts_timeseries_line` 没有现役样本，用前先试点。
3. 过滤条件必须写进 params 的 `adhoc_filters`。运行时前端按 params 生成查询，只写 query_context 没有用。
4. `chart/data` 的 `queries[].filters` 用 `col/op/val` 三个键。写成 `value` 会返回 400（上一轮的误判就源于此）；`extras.where` 也可以用。
5. 中文名在 Rison 过滤里查重不可靠，要拉全量列表在本地比对。
6. 写接口需要带 `X-CSRFToken`（取自 `GET /api/v1/security/csrf_token/`）和 Referer。
7. SQL 度量的参数顺序是（表达式，标签），写反会报 ORA-00904。
8. 数据集口径：ds322–326 是累计桶，主时间列是 DTIME；ds345 单分支且带合计行；ds348 有总计行，ds350 有合计行；ds338、ds347 没有合计行。
9. 慢数据源：ds365 聚合 48.4 秒，ds323 冷查 17.6–18.6 秒。
10. Redis 只动 db0、db1。
11. 普通员工能否取数，依赖 `dashboard_roles` 和 `dashboard_slices`；管理员不受此限制，验收必须用 003158 测。
12. 单独 PUT position_json 不会同步 `dashboard_slices`；`POST /api/v1/dashboard/{id}/charts` 返回 405。新增图表时：
    - 首选在创建图表时带 `"dashboards":[看板id]`（这是 ChartPostSchema 的字段，本环境未实测，做完要核对 `dashboard_slices`）；
    - 不行就用 psql 持锁 INSERT（本批已用过）；
    - 然后 PUT position_json 放置图表。
    删除图表前，先从 position_json 移除它的节点。两边的图表 id 集合必须一致。
13. Oracle 列别名最长 30 字节，中文每字 3 字节。例如「截至17:00挂号人次」是 23 字节，可以用。
14. 联动断言要比对数值，不能比对行数。图头的筛选徽标会把"1"连到 KPI 文本前面，KPI 值要从 Redux 读。
15. Git Bash 下调用 remote_exec 要先 `export MSYS_NO_PATHCONV=1`。端口转发会断，用前先 `curl` 18180 确认。
16. 静态资源可以同版本号原地更新；`remote_exec --put` 是原位写入，inode 不变。
