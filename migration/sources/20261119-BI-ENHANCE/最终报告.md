## 6. 批内教训

1. **position_json 不回填 dashboard_slices**：API 建看板必须逐图 PUT `{"dashboards":[id]}`，否则首载"没有与此组件关联的图表定义"。
2. **insertBefore 参照必须是父节点直接子节点**：React wrapper 嵌套下直接用 querySelector 结果会 NotFoundError，沿 parentElement 上溯到顶层再插。
3. **多度量饼图在本构建不可用**（`reading 'label'`）：一律走"长表数据集 + 单度量 + groupby"（ds374/ds375 模式）；度量 label ≠ 物理列名（ORA-00935）。
4. **Dashboard roles 绑定走 PUT 主端点 body**，`/roles` 子端点本构建不存在（404）。
5. **"Latest month"相对窗不等于最新自然月**（Jinja 模板下解析为 10-01~11-16 混合窗）——月报类图表 time_range 必须显式固定；验收 UI 数值断言要用与对账完全相同的窗口。
6. `map_label_colors` 必须是映射类型；dataset POST 不接受显式 columns（自动注册）。
7. 会话级停滞自愈：ready 探测超时→整会话重启（新端口）+重登录+重导航，比 reload 更可靠。
