## 6. 批内教训（固化为后续批次的注意事项）

1. **不要与 React 拉锯内联 height**：组件会用普通内联覆盖注入的 `!important`；样式表级 `!important max-height`（CSS 变量传值）才是硬上限，链穿透（让 ResizeObserver 观察到正确值）才是根治。
2. **flex 尾对齐容器里 top 读数可为负**：高度正推公式会死循环，必须用"底对齐削减法"或 CSS 兜底。
3. 验收断言方向要审：锁高/收起筛选的收益体现在**滚动区高度净增**，而容器**底边坐标**恒钉视口底沿（测错方向会误报 FAIL）。
4. 查询页顶部存在无 chart-id 的 40px 空筛选容器 holder，主图表定位必须用 `[class*="dashboard-chart-id-"]`。
5. 远程 shell 命令行有长度上限（86KB JS 纯 base64 会超限），传输走 gzip+base64 heredoc。
6. 连续导航的会话级停滞与 profile 占用：分片重启浏览器 + 按目录前缀杀净进程后再清理/重跑。
