#### 1.2 开发 `offline-bundle/hospital_svc/export_service.py`
1. **数据库连接只读获取**：
   - 使用 Superset PostgreSQL 元库中 `dbs` 记录的 `sqlalchemy_uri` / `password`（用环境变量中 Superset 的 `SECRET_KEY` 做对称解密——**禁止硬编码密码**），在子线程内显式初始化 `oracledb.init_oracle_client(lib_dir="/opt/oracle/instantclient")`（幂等捕获已初始化）。
   - 执行查询前在 Oracle 会话执行 `SET TRANSACTION READ ONLY`（仅当引擎允许）并使用 `arraysize = 5000`、`prefetchrows = 5000`。
2. **只读 SQL 与参数安全校验器**：
   - 加载 `export_registry.json` 时进行静态检查：仅允许 `WITH`/`SELECT` 开头、无多语句分号 `;`、无任何写/DDL 关键词（`\b(INSERT|UPDATE|DELETE|MERGE|DROP|ALTER|CREATE|TRUNCATE|GRANT|REVOKE|EXECUTE|CALL)\b` 词边界拦截）。
   - 校验用户输入时间范围合法性（`start <= end`，跨度不超过 `max_span_days`，且禁止全库无界导出）。
   - 校验其余筛选项键名必须在 `allowed_filters` 白名单内，所有值均通过 Oracle `:bind_name` 绑定传参。
3. **日期分片 + 流式写盘 + 50 万行自动分卷**：
   - 将 `[start_dt, end_dt)` 按 `default_chunk_days`（如每 7 天一段）切分为多个时间窗（既防止单条百万级长事务占满 Oracle TEMP/UNDO 与断线前功尽弃，又便于进度条精准推进！）。
   - 按顺序执行每段查询，使用 `while True: rows = cursor.fetchmany(5000)`，逐批格式化行数据（注意：身份证号、处方号、病案号、电话等长数字字符串列若按 CSV 输出防止 Excel 科学计数法或去前导零可保持原文本；日期按标准 `YYYY-MM-DD HH:MM:SS` 输出；`None` 转空字符串）。
   - **格式 A（默认 `zip_csv`）**：
     - 使用 `zipfile.ZipFile(out_path, "w", compression=zipfile.ZIP_DEFLATED, allowZip64=True)`；
     - 维护当前卷 `part_idx = 1`、当前卷行计数 `part_rows = 0`；
     - 每写入第一行或满 `500,000` 行时，关闭当前卷流并开启新卷 `门急诊处方查询_part_{part_idx:03d}.csv`（每卷首行写入 `\ufeff` UTF-8 BOM + 中文表头行）；
     - 整个过程仅维护当前 5,000 行内存缓冲，峰值 RSS 控制在 `< 250 MB`！
   - **格式 B（`csv_gz`）**：使用 `gzip.open(out_path, "wb")` 流式写入单份 `.csv.gz`（含 UTF-8 BOM 与表头）。
4. **并发池、真取消、启动恢复与磁盘守卫**：
   - 任务状态持久化文件：`/app/superset_home/.exports/jobs.db`（使用 Python 标准库 `sqlite3` WAL 模式，天然支持多线程/安全读写与原子更新，禁止裸写多文件 JSON 竞态！）。
   - 启动时（`init_export_worker()`）：扫描 `jobs.db` 中状态为 `queued` 或 `running` 的历史残留任务，统一标为 `failed`，`error_message = "服务重启导致导出任务中断，请重新提交"`。
   - 并发队列：最大同时执行 `MAX_CONCURRENT_EXPORTS = 2` 个导出任务；每个用户当前活跃任务（`queued` + `running`）限制 `<= 2`。
   - **磁盘余量守卫**：创建新任务前检查 `shutil.disk_usage("/app/superset_home").free`，低于 `5 * 1024**3`（5GB）直接返回 `507/400` 拒绝接单并提示管理员清理。
   - **真取消机制**：任务对象注册当前活跃 Oracle `conn`；收到 `POST /hospital-api/export/jobs/<job_id>/cancel` 且校验归属权限后，标状态 `cancelling` 并立即调用 `conn.cancel()` 中止远端 Oracle 查询，流循环退出后清理临时半成品文件，状态落 `cancelled`。
   - **72 小时自动清理**：每次任务结束/创建时顺带（或后台定时线程每小时）清理 `finished_at < now - 72h` 的产物目录与记录。
